## Описание проекта

Многостраничный сайт фото-студии «Удачный момент». Основа — HTML/CSS-проект из КР №1 (`kr1-html-css-shop`). Bootstrap и JavaScript не используются. Сайт адаптирован под экраны от 360px до 1440px, выполнена базовая проверка доступности.


## Структура проекта

```
kr3-responsive-shop/
├── index.html         главная страница
├── catalog.html       каталог с фильтром
├── product.html       страница услуги, таблица характеристик, модальное окно
├── order.html         форма заявки
├── contacts.html      форма обратной связи и контакты
├── css/
│   ├── style.css      основные стили (из КР №1)
│   └── responsive.css адаптивные стили (подключается после style.css)
├── images/            изображения в нескольких размерах (jpg/png и webp)
├── lighthouse/        скриншот проверки Lighthouse
├── README.md
└── .gitignore
```

## Адаптивные решения

- добавлен файл `css/responsive.css`, подключён на всех страницах после `style.css`;
- на всех страницах есть `<meta name="viewport" content="width=device-width, initial-scale=1.0">`;
- применён подход Mobile First: правила для телефона без медиазапросов, затем `@media (min-width: 768px)`, `1024px`, `1200px`;
- навигация: ссылки переносятся на новую строку (`flex-wrap`), увеличена область нажатия; шапка на телефоне не липкая, с 768px липкая;
- hero-блок: на телефоне текст и картинка друг под другом, далее в две колонки (Grid); размер заголовка меняется по ширине экрана;
- сетка карточек (Grid): 1 колонка на телефоне, 2 на планшете, 3 на desktop; в каталоге рядом с фильтром 2 колонки, с 1200px 3;
- каталог: на телефоне фильтр над карточками на всю ширину и не скрывается, с 1024px фильтр слева (220px, липкий);
- страница услуги: картинка и описание в одну колонку, затем в две (Grid);
- responsive images: `max-width: 100%; height: auto`, `picture` с форматом webp, `srcset` и `sizes`, размеры 480px и 800px (камера 480px и 740px), `width` и `height` у всех картинок, `loading="lazy"` у карточек;
- форма: на телефоне одна колонка, поля высотой от 44px, шрифт 16px, кнопка на всю ширину; с 768px две колонки (Grid);
- таблица характеристик в `.table-wrapper` с `overflow-x: auto`, прокрутка только внутри обёртки;
- кнопки высотой не меньше 44px;
- модальное окно по центру экрана, с прокруткой при нехватке места;
- `overflow-wrap: break-word` для длинных слов.

## Доступность

- добавлена ссылка пропуска к основному содержимому (`skip-link`), у `main` есть `id="main"`;
- видимый фокус (`:focus-visible`) был в КР №1 для ссылок, кнопок и полей, проверен на всех страницах;
- у всех полей формы есть `label` с `for`, совпадающим с `id`;
- у изображений осмысленные `alt`;
- на каждой странице один `h1`, заголовки идут по порядку;
- у навигаций есть `aria-label`, текущая страница отмечена `aria-current="page"`;
- у модального окна добавлен `aria-modal="true"`;
- таблица размечена через `caption` и `th scope`;
- контраст текста проверен: цвета заданы через переменные, основной текст и оранжевый акцент (`--color-primary-text`) проходят порог 4.5:1.

## Проверенные ширины

360px, 430px, 768px, 1024px, 1440px. На каждой ширине проверены шапка, навигация, hero-блок, карточки, каталог с фильтром, страница услуги, таблица, формы, контакты, подвал и модальное окно. Горизонтального скролла всей страницы нет.

- шапка не липкая на телефоне;
- двухколоночная форма на планшете и desktop;
- адаптивное модальное окно;
